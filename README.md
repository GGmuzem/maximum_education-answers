# 🧠 AutoAnswer for Maximum Education

Автоматическое расширение Chrome для подстановки ответов в тестах на [education.maximumtest.ru](https://education.maximumtest.ru)

---

## 🚀 Возможности

- 🔍 Получает ответы напрямую из внутреннего API Maximum
- ✍️ Автоматически подставляет ответы в текстовые поля
- ♻️ Работает в режиме реального времени при переходе на задания
- 🧩 Совместимо с большинством видов тестов

---

## 📦 Установка

1. **Скачайте репозиторий**:

    ```bash
    git clone https://github.com/your-username/autoanswer-maximum.git
    ```

2. **Откройте страницу расширений в Chrome**:

    ```
    chrome://extensions/
    ```

3. **Включите режим разработчика** (справа вверху)

4. **Нажмите "Загрузить распакованное расширение"** и выберите папку с проектом

---

## 🧑‍🏫 Как пользоваться

### ✅ Шаг 1. Откройте тест

### 🔁 Шаг 2. Подождите автоматического заполнения

Скрипт:
- Извлечёт `subjectId` и `testId` из URL
- Получит JSON с правильными ответами
- Найдёт на странице поле для ответа
- Вставит правильное значение


### 🧪 Шаг 3. Ручной запуск (если авто не сработал)

Если ничего не произошло:
1. Откройте **DevTools** (F12) → **Console**
2. Пример вывода в консоль:
  - AutoAnswer: правильный ответ →
  - AutoAnswer: 33000
